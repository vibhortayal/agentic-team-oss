Before you start

What you'll need

If any of this is new, Ella walks you through it.

🐙

A GitHub account

Free. Your project and its whole history live there. Create one

🤖

An AI coding tool

Claude Code, Codex, Cursor, Gemini CLI or another. The agents run inside it.

⌨️

Git and a terminal

To copy the team into your project, once. Install Git

🔐

A password manager

Such as Bitwarden (free), for your project's keys. Never paste them in a chat.

Ready when you are

Put the team in your project, open your AI tool and paste one line:

› You are Ella, the Engagement Lead. Read AGENTS.md and .team/roles/engagement-lead.md. <your idea, in your own words>

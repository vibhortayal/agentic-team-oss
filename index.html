What it is

Agentic Team is a free set of instructions for the AI coding assistant you already use. It turns that one AI into a team of ten agents. Each agent has one job. Automatic checks test every change. You only talk to one agent, Ella. She plans the work, runs the others, and comes back when you need to decide something.

Who it's for
People with an app idea who have never written code. Developers who want one AI's work checked by another can use it too.
Why it exists
AI tools write code fast. But they check their own work, forget what you agreed last week and don't tell you the cost before they start.
What you need
A coding assistant like Claude Code, Codex or Cursor. Chatbots like ChatGPT can't run it. What's the difference?

Before you start, know this

This team is for an app you'll keep and change for months.

  • It's new. It hasn't built a real app all the way from idea to launch yet.
  • Setup takes about 15 minutes of typing in a terminal.
  • It's slower than one assistant on its own, and it uses more AI, so it costs more.
  • App builders like Lovable get you to a first version faster.
  • Tests can still miss mistakes. The work is only as good as the AI in your tool.
  • It works best in Claude Code today. Codex and Cursor read the same instructions. Nobody has tried Gemini CLI yet.
  • Putting your app online and storing its data cost extra. You pay those companies yourself.

Start a project

Install the team into your project folder and open your coding assistant inside it. With Claude Code, that means typing claude in the terminal there. Then paste this line with your idea at the end:

› You are Ella, the Engagement Lead. Read AGENTS.md and .team/roles/engagement-lead.md. <your idea, in your own words>

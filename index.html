What it is

Agentic Team is a free set of instructions. It turns the AI coding tool you already use into a small company: ten agents with one job each, a fixed way of working, and checks they can't skip. You only talk to one of them, Ella. She plans the work, runs the others, and comes back when something needs your decision.

Who it's for
People with an app idea who don't write code, and developers who want AI work checked instead of taken on trust.
Why it exists
AI tools write code fast. But they mark their own homework, forget last week's decisions and rarely tell you the cost up front.
What you need
A coding assistant, such as Claude Code, Codex or Cursor. It won't run in an ordinary chat window like ChatGPT, the Claude app or Gemini, because those can't open the files on your computer or run commands there. What's the difference?

Why not just use a chatbot or a coding assistant?

You can, and this doesn't replace them. The team runs inside the coding assistant you already have. What it adds is everything around the code: someone to plan, someone else to check, a written record, and a price before anything starts.

Where it helps, and where it doesn't

An honest list, based on how the team works today.

Good fit

  • An app you'll keep and change for months, not a one-off. The team covers launch, fixes and support as well as the first build.
  • You can't judge code yourself, so you need someone other than the builder to check it.
  • You want the code and its whole history in your own GitHub account, and the freedom to switch AI tools later.
  • You want a price before work starts, and a say before anything is spent.

Not a good fit, or not yet

  • It's early. The team is written and tested on its own, but it hasn't yet carried a real project all the way from idea to launch. That's the next step on the roadmap.
  • Setup still needs a terminal. You install Git and a coding assistant and paste a few commands. The friendly portal that hides this isn't built yet. If that sounds daunting, ask a technical friend to do the first 15 minutes.
  • It's slower and uses more AI than one assistant. Planning and checking are separate runs, so a small change costs more than just asking. For a quick script or a fix, skip the team.
  • App builders are faster to a first version. If you want something good-looking to show by tonight, Lovable or Replit will get you there sooner.
  • Checks lower the risk. They don't remove it. The work is only as good as the AI model in your tool, and tests can miss things.
  • It works best in Claude Code today. That's the only tool with its own installer, where each agent runs as a separate session. Codex and Cursor read the same instructions. Gemini CLI should work but hasn't been tested.
  • Hosting and databases aren't included. You pay those providers directly. Bea prices them in the plan, and free tiers come first.

How a project goes

Six steps. You're needed at three of them. The full walkthrough

  1. Idea

    You describe it to Ella in plain words.

  2. Plan

    One page: what gets built, who builds it, what it costs.

    You approve

  3. Build

    Agents write the code.

  4. Check

    A separate agent tests it.

    You try the preview

  5. Launch

    The app goes live.

    You say go

  6. Keep it running

    Fixes, updates and support.

Start a project

Install the team into your project folder and open your coding assistant inside it. With Claude Code, that means typing claude in the terminal there. Then paste this line with your idea at the end:

› You are Ella, the Engagement Lead. Read AGENTS.md and .team/roles/engagement-lead.md. <your idea, in your own words>
  • A GitHub account. Free. Your project and its history live there. Create one
  • A coding assistant. Claude Code, Codex, Cursor or similar. Most need a paid plan from the AI company.
  • Git and a terminal. Used once per project, to copy the team in. Install Git
  • A password manager. Bitwarden is free. Your project's keys go there, never into a chat.

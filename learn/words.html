Words you'll meet

There are different kinds of AI. A chat app like ChatGPT can only talk with you. To use this team, you need a coding assistant: an AI that can open and change the files on your own computer. Here's how they differ, and the other words this site uses.

A chatbot

ChatGPT, the Claude app, Gemini

  • Talks with you and writes answers, even code
  • Opens and changes files on your computer
  • Runs commands, like installing or testing
  • Plans, checks and records the work as a team

Can't run the team

A coding assistant

Claude Code, OpenAI Codex, Cursor, GitHub Copilot

  • Talks with you and writes answers, even code
  • Opens and changes files on your computer
  • Runs commands, like installing or testing
  • Plans, checks and records the work as a team

Can run the team

Coding assistant + team

Any of those, with Agentic Team installed

The AI words

Chatbot

An AI you talk to in a chat window or app, such as ChatGPT, the Claude app or Gemini. It can write a lot, code included, but it can't open the files on your computer or run anything there. You'd be copying and pasting by hand.

Fine for questions. The team can't run here.

Coding assistantalso: coding agent

An AI that works inside a folder on your computer. It can read and change the files there, and start other programs. It usually asks you before anything risky. You talk to it by typing, like a chat. With Claude Code and Codex, that chat happens in the terminal, the plain text window explained below. Cursor is an app you install, with a chat box down the side. Most need a paid plan from the AI company, so check the price first.

This is where the team runs. Claude Code is the best tested today.

Agent

An AI with a job and the tools to do it. It works through the steps by itself, instead of answering one message at a time. A coding assistant is an agent. Agentic Team gives it ten job descriptions, so it can play ten agents: Ella, Priya, Ian, Vera and the rest.

When this site says "the team", it means those ten agents.

Prompt

What you type to the AI. You only need one to start: the line that tells it to be Ella, followed by your idea.

The computer words

Terminal

A plain window where you type instructions to your computer instead of clicking. On a Mac, press Command and Space, type Terminal and press Enter. On Linux any terminal works. On Windows, install Git for Windows, then press the Windows key, type Git Bash and press Enter. Use Git Bash, not PowerShell, because the setup steps are written for it. Windows hasn't been fully tested yet.

You'll paste a few commands into it, once per project.

Project folder

The folder on your computer that holds your app's files, for example ~/code/family-groceries.

You open your coding assistant inside it, so the AI works on the right files.

Git

A free program that saves snapshots of your project's files, called commits, so every change is recorded and can be undone.

You install it once. The agents use it for you after that.

The GitHub words

GitHub

A website that keeps a safe copy of your project, with its whole history, under your own account. Think of it as Google Drive for code. A basic account is free.

The team writes its plans, tasks and test results there, so nothing lives only in an AI's memory.

Repositoryalso: repo

One project's files plus their whole history. Your repository lives on your computer and on GitHub, kept in step.

Issue

A to-do note on GitHub, like a ticket. Each piece of work the team does has one, with each agent's notes and the results written underneath.

Pull requestalso: PR

A proposed change to the project, shown before it's added. Vera checks it, the automatic checks run on it, and only then is it added.

Branch

A side copy of your project where one change is made. The main version, called main, stays safe until the change is checked.

Merge

Adding a checked change to the main version for real. On GitHub, you click "Merge pull request".

Keyalso: token

A long secret password that lets a program use a service for you, like a spare house key. GitHub calls some keys tokens.

Keep keys in your safe place for keys, never in a chat or in your project's files.

The launch words

Preview

A working copy of your app at a private link, so you can try it before anyone else sees it.

You'll be asked to try one before each launch.

Launchalso: deploy

Putting your app online for real people to use. It never happens without your yes.

Hosting and database

Hosting is the service your app runs on. A database is where its data is kept. You sign up for them yourself, and many have free tiers.

Bea lists the options and monthly costs in your plan.

The team's words

Spec

A short written plan for one change. It says what "done" looks like, so it can be checked.

Priya writes it, and you approve it before any code is written.

Framework

A ready-made set of rules and steps that you build on, so you don't start from nothing. Agentic Team is a framework for AI agents: job descriptions, rules and step-by-step guides that you add to a coding assistant. It isn't an app you install or pay for.

Developers may call it "a multi-agent development framework". It means the same thing.

Playbook

The team's steps for one stage of a project, like a recipe. There are six, from first chat to keeping the app running.

Verdict

Vera's answer after she checks a piece of work. PASS means it does what the spec says. BLOCK means it goes back to be fixed.

Automatic checksalso: gates

Tests that run on GitHub every time something changes. No agent can switch them off, so nobody can skip a step.

Label

A coloured tag on a GitHub issue. It shows which agent has the work, and when you're needed.

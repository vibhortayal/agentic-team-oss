Words you'll meet

"AI" covers very different tools. The team needs one that can work on your computer, which most chat apps can't. Here's the difference, and the other words this site uses.

A chatbot

ChatGPT, the Claude app, Gemini

  • Talks with you and writes answers, even code
  • Opens and changes files on your computer
  • Runs commands, like installing or testing
  • Plans, checks and records the work as a team

Can't run the team

A coding assistant

Claude Code, OpenAI Codex, Cursor, GitHub Copilot

  • Talks with you and writes answers, even code
  • Opens and changes files on your computer
  • Runs commands, like installing or testing
  • Plans, checks and records the work as a team

Can run the team

Coding assistant + team

Any of those, with Agentic Team installed

  • Talks with you and writes answers, even code
  • Opens and changes files on your computer
  • Runs commands, like installing or testing
  • Plans, checks and records the work as a team

This is what the site teaches

The AI words

Chatbot

An AI you talk to in a chat window or app, such as ChatGPT, the Claude app or Gemini. It can write a lot, code included, but it can't open the files on your computer or run anything there. You'd be copying and pasting by hand.

Fine for questions. The team can't run here.

Coding assistantalso: coding agent

An AI that works inside a folder on your computer. It reads and changes files and runs commands, and usually asks before anything risky. Claude Code and Codex run in the terminal. Cursor is an app with a chat panel. Most need a paid plan from the AI company, so check the price first.

This is where the team runs. Claude Code is the best tested today.

Agent

An AI given a job and the tools for it, which works through the steps by itself instead of answering one message at a time. A coding assistant is an agent. Agentic Team gives it ten job descriptions, so it can play ten agents: Ella, Priya, Ian, Vera and the rest.

When this site says "the team", it means those ten agents.

Prompt

What you type to the AI. You only need one to start: the line that tells it to be Ella, followed by your idea.

The computer words

Terminal

A window where you type commands instead of clicking. On a Mac it's the Terminal app, and on Linux any terminal works. Windows hasn't been tested yet. Git Bash, which comes with Git for Windows, is the likeliest to work.

You'll paste a few commands into it, once per project.

Project folder

The folder on your computer that holds your app's files, for example ~/code/family-groceries.

You open your coding assistant inside it, so the AI works on the right files.

Git

A free program that saves snapshots of your project's files, called commits, so every change is recorded and can be undone.

You install it once. The agents use it for you after that.

The GitHub words

GitHub

A website that keeps your project online, with its whole history, under your own account. A basic account is free.

The team writes its plans, tasks and test results there, so nothing lives only in an AI's memory.

Repositoryalso: repo

One project's files plus their whole history. Your repository lives on your computer and on GitHub, kept in step.

Issue

A to-do note on GitHub, like a ticket. Each piece of work the team does has one, with its handoffs and results written underneath.

Pull requestalso: PR

A proposed change to the project, shown before it's added. Vera checks it, the automatic checks run on it, and only then is it added.

The launch words

Preview

A working copy of your app at a private link, so you can try it before anyone else sees it.

You'll be asked to try one before each launch.

Launchalso: deploy

Putting your app online for real people to use. It never happens without your yes.

Hosting and database

Hosting is the service your app runs on. A database is where its data is kept. You sign up for them yourself, and many have free tiers.

Bea lists the options and monthly costs in your plan.

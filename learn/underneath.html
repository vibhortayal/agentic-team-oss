What's underneath

The team is plain text files: a job description for each agent, the steps they follow, automatic checks, and one shared notebook on GitHub where they write everything down. That's why it works with whichever AI tool you already use, and why you can read every rule yourself.

PART A

Roles

One job description per agent: what it does, what it never does, who checks it.
PART B

Playbooks

The process: engagement, research to spec, foundation, build, production, improve.
PART C

The shared record

How every note between agents, and every verdict, is written on GitHub, so any agent can pick up the work.
PART D

Adapters

How the team plugs into each AI tool, and which AI model each agent uses.
PART E

How we work

The method, and the research behind each choice.
